# Ecowalk

Aplikasi mobile berbasis Flutter yang dibuat sebagai tugas kuliah.

## Fitur
- Login dan registrasi
- Lupa password
- Verifikasi OTP
- Halaman profil

## Cara Menjalankan
1. Pastikan Flutter SDK sudah terpasang.
2. Clone repo ini: https://github.com/Febriyyy/ecowalk-pemrograman-mobile.git
